# CEIRF — Gerador de Relatórios

Repositório de documentação técnica e funcional do projeto **CEIRF — Gerador de Relatórios**.

Este repositório centraliza os documentos de apoio ao desenvolvimento do sistema, incluindo modelagem de dados, diagramas, collections de API, decisões arquiteturais e demais materiais relacionados ao projeto.

---

## Sobre o projeto

O **CEIRF — Gerador de Relatórios** tem como objetivo padronizar e automatizar a criação de relatórios institucionais utilizados pela Coordenação Executiva de Infraestrutura da Rede Física — CEIRF.

O sistema será desenvolvido de forma a permitir a evolução para diferentes coordenações e diferentes tipos de relatório.

Nesta primeira fase, o escopo principal está concentrado na automatização do:

> **Relatório de Vistoria de Terreno**

utilizado inicialmente pela **COTEC — Coordenação Técnica**.

A estrutura também está sendo preparada para evolução e utilização por outras coordenações, como:

- COTEC — Coordenação Técnica;
- COPROJ — Coordenação de Projetos;
- COROB — Coordenação de Obras;
- demais coordenações que venham a ser incorporadas ao sistema.
